## 0. Summary and decisions taken

FoundationScale has a verified ASR plane. This plan adds two things: a **TTS plane** (synthesis with measurable, reproducible quality) and an **omni speech-LLM plane** (speech-in / speech-out assistants), **running in parallel from the start as two tracks (U4)**: every omni system is only as good as its audio-out leg and its measurement, and the two tracks now develop that leg together.

Sequencing in one line: **measurement harness first within each track (T0 for TTS, O0 for the omni cascade, starting together)**, **TTS: two co-lead families reproduced before any training — Qwen3-TTS (T1a) and VoxCPM2 (T1b), en/zh plus Vietnamese** (one new kind + one backend in the first slice (D2)), then **T2a** Qwen3-TTS en/zh fine-tuning, **T2b** VoxCPM2 Vietnamese adaptation, **T2c** Qwen3-TTS-Vietnamese transfer experiment (honest, may fail), **T3** VoxCPM2 second-family consolidation + kind decision, **T4** CosyVoice3 RL as the preference-optimisation lane, **T5** MagpieTTS in the NeMo lane (Vietnamese coverage **without** cloning). **Omni in parallel** from a cascade baseline (O0) that everything must beat, Qwen3-Omni decode reproduction (O1), thinker-only training (O2), speech-output training on NeMo `DuplexS2SModel` (O3), full-duplex as honest research (O4).

Languages are **English + Mandarin + Vietnamese, all first-class (U1)**. **Commercial-safe only (U2): no non-commercial data or weights anywhere — there is no research track.** Zero-shot voice cloning is **fully allowed; no gate on it (U3)**. Model licences: **Qwen3-TTS weights+tokenizer+code Apache-2.0 (official fine-tuning exists — `finetuning/` "Qwen3-TTS-Finetuning" guide, V1)**; **CosyVoice (Fun-CosyVoice3-0.5B-2512) Apache-2.0 (V2)**; **VoxCPM2 weights+code Apache-2.0 (V3)**; **Qwen3-Omni-30B-A3B-Instruct Apache-2.0 (V4)**. Everything else is either non-commercial-safe (refused), a NeMo-lane runner-up, or quarantined on missing facts.

### Decisions taken (2026-10-12) — U1–U5 (authoritative)

1. **U1 — Languages:** English + Mandarin + Vietnamese, all first-class. Judge pinning must cover all three; data ordering (§6) targets all three; Vietnamese is a co-equal evaluation column (§7).
2. **U2 — Commercial-safe only:** no non-commercial (NC) data or weights anywhere. No research track exists: research pools are deleted from the plan, NC corpora are refused at ingest (§6), and non-commercial-derived weights (e.g. F5-TTS via Emilia) are refused outright.
3. **U3 — Zero-shot voice cloning is fully allowed:** ship it; **no gate, no consent-evidence requirement, no watermarking requirement on the cloning path**. This decision supersedes D6-c and the framing in the earlier §0/§8; it is recorded here and must be restated in every FS doc that cites a cloning policy. The remaining technical constraint is upstream-side only: MagpieTTS's public release has no zero-shot cloning (F4), so it is a non-cloning family (T5).
4. **U4 — TTS and omni run in parallel from the start:** two tracks (T0–T5 and O0–O4), not sequentially. The omni cascade may consume TTS-track outputs as they become available (O0 talker = Qwen3-TTS en/zh, VoxCPM2 vi) but waits on nothing.
5. **U5 — GPU budget is not given:** use idle GPUs on the allowed GB200 trays, **at most ~2 trays concurrently across both tracks combined**. Every compute figure below is an estimate and stays **UNVERIFIED** until measured. Phase scheduling must fit inside this cap; LoRA-vs-full and FSDP width are chosen at run setup against the cap as measured load demands.

### New open questions (post-2026-10-12)

1. **Fund collecting/licensing more Vietnamese speech?** The commercial-safe vi pool is ~80 h (approximate, **UNVERIFIED** until counted) and thin for a co-lead first-class language (§6). Options: commissioned collection with clean licence chain; per-corpus licence review to unlock gated sets; synthetic augmentation (with the O3 licence-chain caveat on FS-TTS-generated speech).
2. **Cascade LLM identity/size for O0–O2** (the earlier D6-e input): which FS text LLM backs the cascade, and does a larger LLM justify displacing the second tray from the TTS track (U5 cap)?
3. **May FS-TTS-generated Vietnamese speech enter O3 training?** Legal review of the generated-speech licence chain (FLEURS-vi/common-voice prompts + Apache-2.0 weights + FS output terms) is a deliverable before O3; if unclear, O3 trains on natural commercial-safe vi audio only.

## 1. Principles as applied

- **Measurement before training (D1, FS rule 4).** Every family enters decode-only with a reproduced published number before any fine-tuning. `integrated == reproduced`: an FS "supported" tag on a model means our harness measured the paper's/card's value on that card's split, in a capsule (`validation_campaigns/tts_repro/EVIDENCE.md`).
- **Don't over-abstract early (D2, rule 5).** First slice = one kind (`tts_codec_lm`), one backend (native-repo worker for `qwen-tts`), four firing gates. A second abstraction appears only when a second family forces it (VoxCPM2 as co-lead at T1b/T2b/T3 does).
- **Contracts and refusals not conveniences (rule 1).** Typed dataclasses, JSON-lines file contracts, explicit refusal reasons, exits 0/5/95/96 as in `speech_kinds.py`. No silent truncation or dropping; duplicate audio refs refused (the 6,000→820-file bug).
- **Wrap-don't-copy (rules 3, 7).** Adapters call public APIs; any copied snippet (Qwen3-Omni talker glue, Hydra config translation) gets a `foundationscale.upstream.ledger` entry. Pin version + digest per worker.
- **Licence first, always (rule 6).** Undeclared licence refuses at registry check (`empty_field:<id>:license_weights`), never at release time. Data and weights are screened at ingest; `commercial_ok` tags are enforced by CI, and **anything non-commercial is refused outright (U2) — there is no research mix to quarantine it in**.
- **Co-lead for coverage (U1, U3).** Vietnamese is first-class, so the TTS track runs two co-leads (Qwen3-TTS for en/zh quality and the Seed-TTS gold standard; VoxCPM2 for Vietnamese and the tokenizer-free control point). Zero-shot cloning is an ordinary, ungated capability of the co-leads (U3).
- **The ASR plane is reused, not re-coded.** FS WER harness (Whisper judges + FS normalizers + paired bootstrap CIs), coverage gates, runaway/repetition gates, tower-movement, Level-3 reproduction runner — all extended by declaring new gates against the same `Ticket`-style contexts. The Vietnamese judge is an extension of the same pinning discipline (C2).
