### Crosswalk: the 15 named boundaries → the L0–L6 planes

The brief enumerates fifteen abstraction boundaries. The architecture does not use them as
fifteen top-level modules, and that is a deliberate design choice rather than an omission:
several of the fifteen are *not independently substitutable* in this codebase, and a
boundary you cannot swap across is a naming convention, not an abstraction. The table below
is the crosswalk, with the reason wherever a boundary was merged or moved.

| Brief's boundary | Plane | Why there — and where it is *not* a separate seam |
|---|---|---|
| Model | **L2** | Descriptor + provider + weight-bridge spec. Its real seam is the *mapping spec*, not the class. |
| Dataset | **L3** | Sources are declarative; the corpus is a manifest, not an env var (`OMNI_SFT_JSONLS` is the incident). |
| Data Pipeline | **L3** | Merged with Dataset **on purpose**: template + mask + span rendering is where the failures live, and splitting loader from renderer is exactly what let a template silently delete every CoT token. One plane, one contract. |
| Trainer | **L1 + L5** | Deliberately *not* one object. The step loop is vendored (Megatron-Bridge) and belongs in L1; stage sequencing is ours and belongs in L5. Fusing them is what produced 23 forked drivers. |
| Distributed Strategy | **L1** | The execution-plane interface; single-device is the degenerate case, not a branch. |
| Parallelism | **L1** | A *field of the topology object* (D-topology), not an interface. TP/PP/EP/CP/DP are values; only the planner is code. |
| Optimizer | **L1** | Vendored. We own the *config record*, not the implementation — the Muon/AdamW inversion was a provenance failure, not an optimizer one. |
| Scheduler | **L1** | Same, with one added contract: a run whose wall-clock is shorter than `train_iters` never anneals — an exit gate, not a class. |
| Checkpoint | **L5** | Three-level gate (structural → byte/index → semantic parity). The semantic level is the one that has never existed. |
| Evaluation | **L5** | Eval **gates** fed by run manifests, so eval↔run join stops being manual. Advisory-vs-blocking is a gate property. |
| Logger | **L6** | Folded into provenance. Logging that cannot be joined to a resolved config is the defect this whole document is about; a standalone Logger boundary would reproduce it. |
| Launcher | **L6** | One object rendering three backends (Slurm, off-Slurm, local). Today it is 3,000+ lines of divergent shell. |
| Cluster | **L0** | Substrate: nodes, containers, interconnect, IMEX. Endpoints resolved at launch, never literal hostnames in config. |
| Configuration | **L6** | Typed, resolved, and *recorded*. D6's rule: capture the resolved config, not the inputs to it. |
| Runtime | **L0** | Container/runtime backend (pyxis + raw enroot behind one interface). |

Two boundaries in the brief are **absent from the current system entirely** and appear here
only as BUILD-NEW: a pretraining **data plane** (no indexer, no `.bin`/`.idx`, `blend=None`)
and a **services plane** for rollout/judge/teacher processes, which today exist as sidecar
shell scripts with hardcoded hostnames.
