## What this roadmap deliberately does NOT do

* **Does not build a full trainer.** No item here writes `backward()`, a dataloader, an optimizer fit, or model construction — and none should until the seam (P0-3), identity (P1-1) and the adapter interface (P1-5) exist. The thin honest path proposed by the findings (ride a maintained training backend; differentiate via the gate plane) is the only training-related work scheduled, and it lives inside P0-3's wiring, not as a new loop.
* **Does not schedule RL loops, multimodal pipelines, MoE router runtimes, sharded optimizers, sequence parallelism, or serving/export.** All expressible, all unmeasured today (D4 §M14). Scheduling them here would multiply fictions in exactly the docs-claim mode this deliverable series condemns.
* **Does not touch what is adjudicated Keep.** The gate kernel downgrade chain, `storage_id` byte-identity, tri-state probes, the hermetic manifest store, `preflight`'s 0/1/2 exit integrity, the mutation battery's runner/scorer/restore, and `ensure_declaration_is_independent`'s fail-closed stat layer change location or boilerplate only, never semantics. Any row breaching this must carry a new finding.
* **Does not refactor the launchers or the harness.** `launchers/*.sh` (9678 LOC, 5 files), `h100_validation/*.sh` (4986 LOC, 4 files), and the `h100_validation/` harness (31313 .py LOC) are covered by zero internal findings; their only scheduled changes are ingesting defaults the framework hands back to them (P2-0) and the read-only review in P3-0.
* **Does not retire the drift-gate anchored wordings.** The countable statements in this document use only the gate's known forms; the retired "measured .py/.sh/.md lines repo-wide" phrasing does not appear. The current repo-wide denominator is 118342 git-tracked .py/.sh/.md lines repo-wide.
* **Does not introduce line-number citations anywhere.** Every row cites paths and symbol names; the done-when conditions are executables (a gate exits 0, a test passes, a census binding appears) precisely so this roadmap survives the drift it orders.
