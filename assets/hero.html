02

Model Parallelism Techniques

Different ways to split a neural network across multiple GPUs

1

Data Parallelism

DP

Same model replicated on each GPU, different data on each GPU

Different data shards per GPU
2

Tensor Parallelism

TP

Each GPU holds a slice of every layer (tensor / hidden dimension split)

Same data replicated on all GPUs
3

Pipeline Parallelism

PP

Different layers (stages) on different GPUs, executed sequentially

Micro-batches flow through the pipeline
4

Expert Parallelism (Mixture-of-Experts)

EP

Different experts on different GPUs, a router selects which experts run

Router selects experts across GPUs
Key Takeaway: Different parallelism strategies solve different scaling challenges. Scalable Efficient Optimized
