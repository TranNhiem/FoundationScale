Parallelism strategies

how a model and its data are split across GPUs
1Data parallelDP
Full model on every GPU, a different data shard on each
DDPgradients all-reduced after each step
2Fully sharded data parallelFSDP
Each GPU stores a slice of every layer, gathered on use
FSDP2params, grads & optimizer state sharded
3Tensor parallelTP
Each GPU holds one slice of every layer's weight matrices
Megatron-Bridgesplits the hidden dimension inside a layer
4Pipeline parallelPP
Layers split across GPUs; micro-batches flow through
Megatron-Bridgeforward → , backward ⇠ between stages
5Expert parallelEP
Mixture-of-Experts: experts live on different GPUs
Megatron-Bridgefor MoE models
6Context parallelCP
A long sequence is split across GPUs
Megatron-Bridgefor long-context training
