Guardrails in code not just prose

probe-first
Plan only against what was measured to run.
confirm-before-launch
No job without the user's plan-hash read-back.
measured-or-unmeasured
A check that did not run is never reported as a pass.
refusal-surface
Refusals name exactly what is missing.

Four verdicts exit codes

0PASS
5RED
95UNMEASURED
96REFUSED
Combined results take the worst verdict; an empty set is UNMEASURED, never a vacuous pass.

Every rule is tested

Each rule ships a fixture that must make it fire, and each skill ships routing & behaviour evals that measure whether an agent picks and follows it.
